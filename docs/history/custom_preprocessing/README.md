# Historical custom preprocessing

This directory preserves the superseded custom/from-scratch address parsing and
pilot program, its experiments, review protocols, diagnostic deviations, and
freeze records. The corresponding source/tests/cluster assets remain available
for exact historical reproducibility, and the baseline tag is
`baseline/custom-preprocessing-2026-08`.

This material is not the active library-first Stage 0–19 architecture and must
not be read as current stage status or permission to access protected
evaluation sets. In particular, historical `LOCKED_EVALUATION` terminology is
separate from the current 15,000-row Benchmark V1 HOLDOUT, which remains sealed.

The accepted active pipeline is documented in [`docs/PIPELINE.md`](../../PIPELINE.md)
and [`docs/stages/`](../../stages/README.md). Historical files retain their
original scientific names so commits, reports, and execution evidence remain
traceable.

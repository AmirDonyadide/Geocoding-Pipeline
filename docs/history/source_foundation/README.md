# Historical source foundation

These records describe the accepted Phase 1 raw-file inventory and Phase 2
lossless CSV-to-Parquet staging work that library-first Stage 0 and Stage 1
reuse. They retain historical names because their contracts, reports, and code
were accepted under those names.

| Record | Purpose |
|---|---|
| `PHASE01_DESIGN.md` | Original inventory/parser design |
| `PHASE01.md` | Sanitized accepted inventory evidence |
| `PHASE02_DESIGN.md` | Original lossless staging design |
| `PHASE02.md` | Sanitized accepted staging evidence |
| `DATA_INPUT.md` | Historical source-input observations |

The current production population is 1,411 files and 141,048,582 rows; older
population counts in these immutable-context reports describe the specific run
they documented and are not the current production scope. Current stage status
is in [`docs/stages/`](../../stages/README.md).

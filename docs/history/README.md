# Historical records

This directory separates historical scientific provenance from the active
library-first documentation. Moving a record here does not change its commit
history, scientific meaning, or reproducibility.

- [`source_foundation/`](source_foundation/README.md) contains the accepted
  historical Phase 1 inventory and Phase 2 lossless staging designs/reports that
  underpin library-first Stage 0 and Stage 1.
- [`custom_preprocessing/`](custom_preprocessing/README.md) contains the
  superseded custom parsing/pilot program, experiments, review protocols, and
  freeze records. It is preserved for provenance and regression history, not as
  the active Stage 0–19 architecture.

Current colleagues should start with the root README, `docs/PIPELINE.md`, and
`docs/stages/`. Historical records do not authorize a new run or later stage.

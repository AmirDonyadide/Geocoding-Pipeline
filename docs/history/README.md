# Historical records

[source_foundation/](source_foundation/README.md) preserves the Phase 1 inventory
and Phase 2 lossless-staging designs/reports that underpin Stages 0–1. Names,
populations and stop statements describe their original checkpoints; the old
Phase packages and entry points have been removed.

Use the [current pipeline](../PIPELINE.md), [stage records](../stages/README.md)
and [progress index](../DEVELOPMENT_PROGRESS.md) for active work. Historical
records explain provenance and do not authorize another run.

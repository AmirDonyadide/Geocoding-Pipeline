# Historical records

This directory separates accepted source-foundation provenance from the active
library-first documentation. Its records use the terminology in force when
Stage 0 and Stage 1 were developed.

- [`source_foundation/`](source_foundation/README.md) contains the accepted
  historical Phase 1 inventory and Phase 2 lossless staging designs/reports that
  underpin library-first Stage 0 and Stage 1.

Current colleagues should start with the root README, `docs/PIPELINE.md`, and
`docs/stages/`. Source-foundation records do not authorize a new run or later
stage.
